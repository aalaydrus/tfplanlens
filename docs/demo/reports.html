tfplanlens demo reports

View the repository on GitHub   About the tool

Real tfplanlens report -f html output from the example plans in the repository. Open one and use the search, grouping and per-resource detail drawers.

Everything here is made up. The plans were produced against a local AWS emulator (no real AWS account), with dummy account IDs such as 123456789012. This page makes no network requests and runs no tracking.

Start here

  • Orders platform: a proposed change A made-up AWS stack (S3, DynamoDB, SNS, SQS, IAM, Secrets Manager). A stateful DynamoDB table is replaced (deletion protection off), a queue is deleted, each with what depends on it, and drift on an IAM role is shown.
  • Cross-account apply The plan is applied from one account and targets another, with a cross-account warning.

More scenarios

  • Destroy A destroy plan: every resource listed under Danger.
  • Drift A plan alongside changes made outside Terraform.
  • Refresh only A refresh-only plan: it updates state and changes nothing.
  • Import A plan with imported resources.
  • Modules and providers Replacements inside modules.
  • Replace reasons Why Terraform decided to replace or delete each resource.
  • Complex plan Creates, updates, replaces, deletes and a forgotten resource in one plan.
  • Simple plan One create, update, replace and delete.
