# tfplanlens v0.1.0

The first release. tfplanlens reads the JSON from `terraform show -json`
**offline** (no AWS credentials, no Terraform, no network, no LLM) and tells you
what matters first: deletes and replaces.

## What it does

- **Danger first.** Every delete and replace with the reason in plain English, a
  STATEFUL badge, what depends on it in the plan, deletion protection and final
  snapshot where the plan says, and a warning when a `count` or `for_each` change
  looks like an accidental shift. Ordered stateful first, then without deletion
  protection, then by dependents.
- **Which account.** Where `terraform apply` runs versus where each resource lands.
- **Also.** Drift, moves, imports, apply waves, a `diff` between two plans, several
  plans in one report, an interactive `tui`, and `--fail-on` rules for CI.
- **Formats.** `text`, `markdown` (a PR comment), `html` (one offline file with a
  Danger side panel), `json` (stable, see `docs/json-schema.md`) and `brief`
  (`-f brief --top N`: the top N changes that need attention, ranked, for a
  reviewer or a code review agent).
- **Secrets.** Values Terraform marks sensitive are never printed, and
  secret-looking values it does not mark are hidden too. This is best effort:
  read `docs/SECRETS.md` for what is and is not hidden.

## Install

Download a binary for linux, macOS or Windows (amd64 or arm64) from this release
and check it against `checksums.txt`, or with Go 1.25 or newer:

```sh
go install github.com/aalaydrus/tfplanlens/cmd/tfplanlens@v0.1.0
```

There is no Homebrew formula yet.

## Known limits

- Tested on real Terraform 1.16 plans and on plans made against a local AWS
  emulator. It has not been tried on a real, large AWS stack.
- Deletion protection and final snapshot lines exist only for DynamoDB tables
  (checked in a real plan) and RDS instances and clusters (attribute names taken
  from the provider documentation, not yet seen in a real plan).
- "Used by N+" counts and apply waves are lower bounds: other stacks,
  `replace_triggered_by` and references through a local value are not in the plan.
- It cannot say which commit caused a change or who else uses a resource.
- This is an early release: flags and output may still change.

Report problems at <https://github.com/aalaydrus/tfplanlens/issues>; security
issues as described in `SECURITY.md`.
